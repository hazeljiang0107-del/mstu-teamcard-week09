# Meet our team (MSTU Week 09)

A team page built with HTML, CSS, and JavaScript. Each teammate adds one card.

## Adding your card

1. Pull the latest changes: `git pull origin main`
2. In `index.html`, copy the commented-out template card and paste it above the "Add your card below this line" comment.
3. Fill in your name, major, image, fun fact, and tags. Change `--card-tint` to pick your card's image background color.
4. Put your image in the `images/` folder.
5. Open `index.html` in a browser to check it. Card numbers and the team count update automatically.
6. Commit and push: `git add . && git commit -m "Add <your name>'s card" && git push origin main`
7. Tell the next teammate it's their turn.
